# TokyoYelp

## Description

Our app recommends food and restaurants to users using a Kaggle dataset from Tabelog, a Japanese restaurant-review platform similar to Yelp. The dataset helps match users with restaurants based on cuisine, location, budget, ratings, and search preferences.

Tabelog is a Japanese-style Yelp, which Japanese citizens mainly use for food and restaurant recommendations. Foreigners may have a hard time navigating this app, so our app provides easy and intuitive usability for English-speaking foreigners.

## Features

- Search for restaurants using keywords
- Filter restaurants by cuisine type
- Filter restaurants by neighborhood
- Filter restaurants by budget
- Filter restaurants by Tabelog rating
- View restaurant information, including address, genre, rating, reviews, and dinner budget
- Receive restaurant recommendations based on user preferences
- Use AI to select a restaurant based on personalized preferences
- Browse Japanese restaurant data from Tabelog
